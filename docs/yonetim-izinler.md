# Yönetim paneli ve yetki sistemi

Bu dosya `CLAUDE.md`'den taşındı; içerik aynıdır. Yalnız bu konuda çalışırken oku.

- Yönetim (`AdminPanel.tsx`, yalnız yönetici): "Kişi Ekle" (sayfa başlığı) Edge Function `admin-users` (kaynak `supabase/functions/admin-users/index.ts`, yayın MCP `deploy_edge_function`; servis anahtarı yalnız orada; işlemler create/password/rename, çağıran `is_admin()` olmalı) ile hesap açar, hesap aktif başlar, giriş bilgisi kopyala/WhatsApp. Yetkiler `profiles.perms` (`lib/access.ts`): bölümler `MODULES` (quotes, customers, materials, suppliers, collections, expenses, notes, reports: none/view/edit) + ek izinler `FLAGS` (others = herkesin tekliflerini görür; kapalıysa yalnız kendi açtığı teklifler: `quotes.owner_id` (varsayılan `auth.uid()`), SQL `sees_all()`, son hareketler ve haftalık özet bildirimi de kapalı, hatırlatma yalnız kendi teklifine, numara sırası `quote_max_seq`, aynı teklif no başkasında varsa formda uyarı `quote_lookup` (yalnız firma/tarih/ekleyen) ve kaydedince yeni kayıt açılmaz: `quote_share_me` o teklifi `shared_with`'e ekler, mevcut kayıt güncellenir (tek kayıt; sahibi değişmez); remove = kayıt silme, balances = cari bakiye, ai = Sor/Hazırla) + şablonlar `PRESETS`; eksik anahtarın varsayılanı `levelOf` (eski kullanıcılar etkilenmez, SQL `can()`/`can_remove()` ile aynı). Veritabanı: silme politikaları `can_remove()`; müşteri okuma/yazma aktif herkese açık (teklif kaydı müşteriyi yazar), silme yetkiye bağlı. Deneme: `/preview3/app.html?p=admin(&modal=adduser)`.
