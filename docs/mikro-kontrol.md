# Mikro teklif kontrolü

Bu dosya `CLAUDE.md`'den taşındı; içerik aynıdır. Yalnız bu konuda çalışırken oku.

- Mikro teklif kontrolü (`lib/quoteCheck.ts`, `runQuoteCheck`): "PDF'ten doldur" sonrası uyarı verir, kaydı engellemez; kırmızı yok (sarı = bakılmalı, gri = bilgi). Fiyat güncel liste fiyatıyla; aynı markada aynı oranda fark varsa tek "liste değişmiş" notu (eski teklif fiyatıyla karşılaştırma yalnız listesiz üründe). İskonto marka (liste) bazında, SQL `quote_brand_ref` geçmiş tekliflerden anında: önce firmanın o markada son aldığı, yoksa markanın son 6 ay aralığı, yoksa liste iskontosu; vade ayrı (peşin/kredi kartı yalnız peşin tekliflerle, GÜN'lü/boş vadeli; vade değişince kontrol yenilenir; peşin geçmişi yoksa liste iskontosuyla yalnız gri not); fazlası sarı, azı gri; aynı teklifte markada farklı iskonto sarı (ayrı hafıza tutulmaz, bu "iskonto hafızası" değildir). Ürün kodu `catalogLookup` (`lib/pdfQuote.ts`) birebir adla; aynı adlı birden çok kart varsa fiyatı/stoku olan tek kart, yoksa cihazdaki tekliflerde en son kullanılan, ayırt edilemezse kod boş + "katalogda aynı adlı N kart var" uyarısı. Listesiz ürüne `supplier_suggest` (benzerlik + birim fiyat birebir, 5 aday) + "Listede ara"/"Hiçbiri" (`SuggestMatchBox.tsx`).
